Privacy Policy

OCPS Repair Validator  ·  Last updated: April 14, 2026

No personal data is sold or shared with third parties

1. Overview

OCPS Repair Validator is a Chrome browser extension that provides real-time repair order validation on Odoo repair pages used internally by OCPS technicians. This policy describes what data the extension accesses, how it is used, and how it is stored.

2. Data the Extension Accesses

  • Odoo session information — The extension reads your Odoo login (email/username) from the active Odoo session via /web/session/get_session_info. This is used solely to pre-fill the "User email" field in the repair note generator.
  • Repair order data — The extension reads repair order records, parts, log notes, sales orders, and related Odoo records from the Odoo instance you are currently logged into. All requests are made directly to the Odoo server using your existing authenticated browser session (same-origin fetch, no passwords or tokens are stored by the extension).
  • Clipboard — When you click "Copy Note," the extension writes formatted note text (and optionally images) to your system clipboard. No clipboard data is read or transmitted.
  • Camera — If you use the "Take Photo" feature, the extension requests temporary camera access to capture a single image. The image is placed directly into the note editor and never uploaded or stored externally.

3. Local Storage

The extension stores the following data locally in chrome.storage.local on your device:

  • Odoo username / login — Cached after a successful session check to pre-fill the note template. Overwritten on each login.
  • Seen announcement IDs — A list of integer IDs used to avoid showing the same system announcement twice. No message content is stored.
  • Extension file hash — An MD5 hash used internally to detect when extension files have been updated on the server. No user data is involved.

This data never leaves your device and is not shared with anyone.

4. Internal API Calls

When deployed in an internal environment, the extension may communicate with a local network server (e.g., 10.x.x.x:3131) to fetch announcements, blocked serial lists, and UI control configurations set by administrators. These calls are made only within your organization's private network and do not involve any external third-party services.

The Chrome Web Store version of this extension does not include the private-IP host permission and therefore makes no such calls.

5. Data We Do NOT Collect

  • We do not collect, transmit, or store any repair order data on external servers.
  • We do not track browsing history or behavior outside of Odoo repair pages.
  • We do not use analytics, advertising SDKs, or any third-party tracking libraries.
  • We do not sell, rent, or share any user data with third parties.

6. Permissions Justification

  • activeTab / scripting — Required to inject the validation panel into the active Odoo repair page.
  • storage — Required to cache the Odoo username and seen-announcement IDs locally.
  • tabs — Required to detect when the user navigates to a repair page in order to trigger validation.
  • notifications — Used to surface system announcements when an Odoo tab is not in focus.
  • alarms — Used to schedule periodic background checks (e.g., every 30 seconds).
  • clipboardWrite — Required to copy the generated repair note (with images) to the clipboard.

7. Changes to This Policy

If this policy is updated, the "Last updated" date at the top of this page will change. Continued use of the extension after any update constitutes acceptance of the revised policy.

8. Contact

For questions about this privacy policy or the extension, contact the developer directly through your internal OCPS channels or via the GitHub repository.
